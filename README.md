# EVA TAQA Global Presence

Build a premium bilingual corporate website for EVA TAQA with TWO fully localized versions:

1. English version: /en
2. Arabic version: /ar

IMPORTANT:
These must feel like two professionally designed versions of the same international brand.

Do NOT simply translate the English website.

The Arabic website must be designed natively for Arabic and use a complete RTL layout.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Create a language switcher in the main navigation:

- Direction: LTR
- English typography
- English navigation
- English content

Arabic:
- URL: /ar

/en/contact

Arabic:

If the user is viewing:

and clicks العربية,

take them to:

/ar/services/power-transmission

If the user clicks English from the Arabic version, return them to the equivalent English page.

Detect the browser language on the first visit if appropriate, but DO NOT automatically redirect users every time they visit. Allow the user to control the language.

Store the selected language preference.
